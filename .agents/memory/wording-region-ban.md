---
name: Wording ban on "region"
description: Site-wide rule — never use the word "region" in any language in user-facing text
---
The word "region" (IT regione/regioni, FR région, DE Region/regional, EN region/regional) must NEVER appear in user-facing text, in any of the 4 locales.
**Why:** user directive (Jul 2026) — in Ticino/Switzerland one speaks of Cantoni, not regions.
**How to apply:** use Cantone/canton/Kanton (with correct gender/case: del tuo Cantone, aus Ihrem Kanton, de votre canton) or, where "canton" is factually wrong (cities, lake areas, snow zones), neutral words: zona/zone, Gebiet/Raum, area (e.g. "Raum Biel", "Arc lémanique", "Genferseegebiet", "Lake Geneva area"). Code identifiers (object key `region:`) may stay. When adding new content, scan it for these words before shipping.
