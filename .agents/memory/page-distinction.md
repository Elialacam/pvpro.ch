---
name: Distinct informational pages
description: User expectations for topic pages and navigation destinations on PvPro.ch.
---

Pages should be genuinely distinct in content and presentation, not repeated generic layouts. When the user requests a page for choosing the best installer, an anchor on “How it works” does not satisfy that request.

**Why:** The user explicitly requested distinct pages, then rejected the repetitive result and the installer-choice menu destination because it was only a section of the process overview.

**How to apply:** Build requested topic pages around practical, topic-specific guidance and link the menu to the actual page. Preserve unrelated pages and sections that the user says are satisfactory.

For subsidy pages, the user explicitly wants standalone federal and cantonal guides, URL wording in the page's language, exhaustive content based on data already on the site, and the approved navy/white/yellow solar-page style.

**Why:** The user rejected English subsidy fragments on German URLs and the reuse of the general subsidy overview as the destination for both subjects. Distinct content must still follow the approved visual family.
