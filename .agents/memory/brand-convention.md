---
name: PVPro.ch brand convention
description: Exact project-wide brand spelling and SEO title suffix rule.
---

Use `PVPro.ch` everywhere the brand is shown to users or search engines. Never use `PV Pro`, `PVPro`, or `PvPro`. SEO titles must end exactly once with ` | PVPro.ch`.

**Why:** The user requires one consistent brand identity across visible text, image alternatives, metadata, footers, authorship, and structured data, and duplicate legacy suffixes previously appeared in search metadata.

**How to apply:** When adding or editing user-facing content or metadata in any language, use the exact spelling and verify that title templates do not append a second suffix. Do not rename technical identifiers, event names, routes, domains, or file paths merely to match the display brand.
